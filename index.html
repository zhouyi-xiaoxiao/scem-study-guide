CHAPTER 03

03 · 索引与对象 / Indexing and objects

取第几个、去掉哪个、满足哪个条件？

R 从 1 开始 / R is one-indexed

x[1] 取第一个元素；x[-1] 排除第一个元素；x[0] 返回长度为零的结果，不是第一个元素。正索引选择位置，负索引排除位置；不要在同一索引里混合正数与负数。

Use positive positions to keep values and negative positions to exclude them. Zero selects no positions. Positive and negative subscripts cannot be mixed in the same index (apart from zeros).

R · illustrative example
x <- c(4, 8, 12, 16)
x[1]       # first value
x[-1]      # all except first
x[0]       # empty numeric vector
x[c(2, 4)] # positions 2 and 4

逻辑索引 / Logical indexing

条件 x > 8 先生成 TRUE/FALSE 向量，再据此取值。& 和 | 做逐元素的“且／或”，适合向量筛选；&& 和 || 是标量控制流运算，不用来筛整列。含 NA 的逻辑条件可能把 NA 带入 base R 索引结果，先明确缺失值策略。

A comparison creates a logical vector used to select values. Use vectorised & and | for element-by-element conditions, not scalar && and ||. Missing logical indices can propagate missing entries in base R subsetting.

R · illustrative example
x <- c(4, NA, 12, 16)
x[!is.na(x) & x > 8]
(x > 8)
is.na(x)

行、列、字符串 / Rows, columns and names

df[行, 列] 中逗号左边是行，右边是列；空着表示全部。df[, "score"] 按字符串列名取列；df$score 不加引号；dplyr::select(df, score) 通常直接使用列名。tibble 的单方括号通常保留表格形状；[["score"]] 或 pull(score) 取向量。

In df[rows, columns], a blank dimension means all entries. Character column names are quoted, while $ and ordinary dplyr expressions use bare names. Tibbles generally preserve a table with [; use [[ or pull() when you need a vector.

R · illustrative example
df <- data.frame(name = c("A", "B"), score = c(6, 9))
df[1, ]
df[, "score"]
df$score
df[["score"]]
dplyr::select(df, score)
CHAPTER 04

04 · 数据类型、企鹅数据和缺失值 / Data and missingness

先确认单位和对象类型，再开始计算。

认识变量 / Know your variables

palmerpenguins 的 penguins 是适合练习的观测数据表，记录企鹅物种、岛屿和若干测量值。body_mass_g 单位为克，flipper_length_mm 单位为毫米。物种等类别不是连续数值；factor 具有类别水平，不能把内部整数编码当成测量值。原始采样设计也不等于任意总体的简单随机样本。

The penguins dataset contains species, island and biological measurements. Units matter: grams are not kilograms and millimetres are not centimetres. Factors encode categories rather than measured quantities. The real observational study is not automatically a simple random sample from every possible penguin population.

R · illustrative example
dplyr::glimpse(palmerpenguins::penguins)
levels(palmerpenguins::penguins$species)
summary(palmerpenguins::penguins$body_mass_g)

NA 不是零 / Missing is not zero

NA 表示未知或缺失，不能用 x == NA 判断；使用 is.na(x)。mean(x) 遇到 NA 通常返回 NA；na.rm = TRUE 只在这次运算中忽略缺失，不会修复数据，也不能保证统计上没有偏差。若全部缺失，均值可能为 NaN。

Test missingness with is.na(), not == NA. Removing missing values for a calculation is not an imputation strategy and does not guarantee unbiased inference. Report how many usable observations remain; an all-missing group needs explicit handling.

R · illustrative example
x <- c(7, NA, 11)
mean(x)
mean(x, na.rm = TRUE)
sum(is.na(x))
sum(!is.na(x))

只移除当前分析需要的缺失项 / Targeted cleaning

分析体重时，可以只筛掉体重缺失的行；不必因为另一个无关变量缺失而丢整行。每次过滤都要记录分析样本发生了什么变化。不要无解释地把所有变量都做完整案例删除。

Define the variables needed for the question, then handle missingness for those variables. Dropping every row with any missing field can remove observations unnecessarily and change the population being described.

R · illustrative example
mass_data <- palmerpenguins::penguins |>
  dplyr::filter(!is.na(body_mass_g))
nrow(palmerpenguins::penguins)
nrow(mass_data)
CHAPTER 05

05 · dplyr 六个动作 / Six data verbs

每一步都预判输出的行数和列数。

选列与筛行 / Select versus filter

select() 改变保留哪些变量，filter() 改变保留哪些观测。筛选条件计算为 NA 的行不会被 filter() 保留。先用一句话说明“我要什么样的行，保留哪些列”，再写代码。

select() chooses variables; filter() keeps observations whose condition is TRUE. Predict the output shape before running the operation. A missing condition is not treated as TRUE.

R · illustrative example
palmerpenguins::penguins |>
  dplyr::filter(island == "Dream", !is.na(bill_length_mm)) |>
  dplyr::select(species, bill_length_mm, bill_depth_mm)

新增与排序 / Mutate and arrange

mutate() 新增或修改列，通常保留行数；arrange() 改变行顺序，不自动删行。单位换算是清楚的 mutate 示例；排序后不要把第一行误当作原来的第一只企鹅。

mutate() adds or changes columns, while arrange() reorders rows. Neither ordinary operation is intended to reduce the number of observations. Keep track of units and identifiers after sorting.

R · illustrative example
palmerpenguins::penguins |>
  dplyr::mutate(mass_kg = body_mass_g / 1000) |>
  dplyr::arrange(dplyr::desc(mass_kg)) |>
  dplyr::select(species, mass_kg)

分组与汇总 / Group and summarise

group_by() 给后续操作设定分组；summarise() 用每组统计量形成新表。n() 统计组内所有行，不等于某列非缺失数。用独立的新名称保存汇总结果，并用 .groups = "drop" 明确去掉分组状态。

Grouping changes the scope of subsequent calculations. n() counts rows, including those with missing measurements; explicitly count observed values for the denominator of a measured-variable summary. New summary names prevent accidental overwriting.

R · illustrative example
palmerpenguins::penguins |>
  dplyr::group_by(island) |>
  dplyr::summarise(
    rows = dplyr::n(),
    observed = sum(!is.na(flipper_length_mm)),
    mean_flipper_mm = mean(flipper_length_mm, na.rm = TRUE),
    .groups = "drop"
  )

管道与向量化 / Pipes and vectorisation

x |> f() 把左边对象传给右边函数的第一个参数。普通 mutate(a + b) 已经逐行执行向量加法，不需要 rowwise()。但 mean(c(a, b)) 会把整列拼接后算一个总体均值；要逐行合并多列，可使用 rowMeans() 或明确的 rowwise()，最后 ungroup()。

A pipe passes a result forward. Arithmetic on equal-length columns is already vectorised. In contrast, a summary such as mean(c(a, b)) pools values unless a row-wise context is explicitly established. Avoid adding rowwise() reflexively.

R · illustrative example
toy <- tibble::tibble(a = c(2, 4), b = c(8, 10))
toy |> dplyr::mutate(total = a + b, average = (a + b) / 2)
toy |>
  dplyr::rowwise() |>
  dplyr::mutate(average = mean(c(a, b))) |>
  dplyr::ungroup()
CHAPTER 06

06 · 贝叶斯：条件方向不能反 / Bayes and base rates

以下是虚构筛查例子，仅用于概率教学。

四个概率 / Four probabilities

令 D 表示具有某种特征，+ 表示检测阳性。先验 p=P(D) 是检测前的比例；灵敏度 s=P(+|D)；特异度 c=P(-|非D)；假阳性率为 1-c。目标是后验 P(D|+)，不能把它直接等同于灵敏度。

Let D denote the target condition and + a positive result. Prevalence p is the prior probability, sensitivity s is P(+|D), and specificity c is P(-|not D). The false-positive rate is 1-c. The desired posterior P(D|+) reverses the conditioning direction.

分母是全部阳性 / The denominator includes all positives

P(D|+) = sp / [sp + (1-c)(1-p)]。分子是真阳性的总体比例；分母把真阳性和假阳性相加。这个二分类模型假设两类互斥且穷尽，并把给定灵敏度、特异度视为适用于目标人群。分母为零时，该条件概率未定义。

Bayes gives P(D|+) = sp / [sp + (1-c)(1-p)]. Its denominator is the probability of any positive result, not the probability of having the condition. If no positive outcome is possible, conditioning on one is undefined.

用 10,000 个对象理解 / Natural frequencies

使用 p=0.03、s=0.90、c=0.96：10,000 个对象中预期 300 个具有特征，产生 270 个真阳性；9,700 个不具有特征，产生 388 个假阳性。阳性中具有特征的比例为 270/658≈41.0%。这些是理论期望，不是一次模拟的固定人数。

With p=.03, s=.90 and c=.96, 10,000 hypothetical objects yield expected counts of 270 true positives and 388 false positives. The posterior is 270/658, about 41.0%. These are expected frequencies, not guaranteed realised simulation counts.

R · illustrative example
p <- 0.03
sensitivity <- 0.90
specificity <- 0.96
true_positive <- p * sensitivity
false_positive <- (1 - p) * (1 - specificity)
posterior <- true_positive / (true_positive + false_positive)
posterior

基率为什么重要 / Why the base rate matters

固定灵敏度和特异度时，降低先验比例会降低阳性预测值。原因不是检测突然变差，而是假阳性来自一个更大的非特征群体。把先验改为 0.003，先预测方向，再计算；不要把教学参数用于真实医疗决策。

With sensitivity and specificity fixed, a lower prior probability produces a lower positive predictive value. False positives can dominate when the negative population is much larger. Change only the prior and predict the direction before calculating. This is a probability exercise, not clinical advice.

CHAPTER 07

07 · 从公式到模拟 / Simulation and Monte Carlo

模拟检查理解，而不是代替明确的模型。

先产生状态，再产生观测 / Generate states, then tests

rbinom(N, size=1, prob=p) 产生 N 个 Bernoulli 结果。先模拟真实状态，再按状态给每个对象不同的阳性概率；不能用同一个无条件概率生成两者，否则会破坏模型中条件依赖关系。

Generate the latent state first, then simulate a test using the appropriate conditional probability. A Bernoulli draw is a binomial draw with size=1. Generating state and test independently would not represent the specified sensitivity and specificity.

R · illustrative example
set.seed(4102)
N <- 100000
p <- 0.03
sensitivity <- 0.90
specificity <- 0.96
state <- rbinom(N, size = 1, prob = p)
positive_probability <- ifelse(state == 1, sensitivity, 1 - specificity)
positive <- rbinom(N, size = 1, prob = positive_probability)
number_positive <- sum(positive == 1)
mc_posterior <- if (number_positive > 0) {
  mean(state[positive == 1])
} else {
  NA_real_
}
c(number_positive = number_positive, mc_posterior = mc_posterior)

比较同一组参数 / Compare like with like

理论值和模拟值必须使用完全相同的 p、灵敏度和特异度。模拟结果不会恰好等于公式；记录阳性样本数，再用 sqrt(qhat*(1-qhat)/m) 粗略估计阳性比例的 Monte Carlo 标准误，m 是模拟中阳性数量。

Match every parameter before comparing simulation with theory. Conditional on m positive observations, sqrt(qhat*(1-qhat)/m) is a useful approximate Monte Carlo standard error for their estimated true-positive proportion, away from extreme small-sample cases.

随机种子不是准确率保证 / Seeds do not ensure accuracy

换种子看结果能否在合理范围内波动；把模拟规模增加四倍，Monte Carlo 误差通常约减半。这个误差来自模拟次数有限，不是原始数据中测量误差，也不是模型参数的不确定性。

A seed enables repeatability, not accuracy. Quadrupling independent Monte Carlo draws typically halves Monte Carlo standard error. That error is distinct from measurement error and uncertainty about the model parameters.

CHAPTER 08

08 · 参数、估计量、估计值 / Parameters and estimates

一个是总体性质，一个是规则，一个是这次得到的数。

三个层次 / Three levels

参数 μ 是总体均值；估计量 X̄=(1/n)ΣXi 是抽样前仍随机的计算规则；估计值 x̄ 是把这次数据代入后得到的数。对同一数据换单位会改变数值尺度，但不改变这三者之间的逻辑关系。

A parameter describes the population. An estimator is a rule applied to random data, so it is random before the sample is observed. An estimate is the realised value of that rule. Keep these distinctions explicit when interpreting a simulation.

均值、方差与标准差 / Mean, variance and SD

在 iid 且方差有限时，样本均值是 μ 的无偏估计。常见样本方差 s²=Σ(xi-x̄)²/(n-1)，R 的 var() 使用 n-1；它对总体方差无偏，但 sqrt(s²) 不因此自动成为总体标准差的无偏估计。方差单位是原单位的平方，标准差与数据同单位。

Under iid sampling with finite variance, the sample mean is unbiased for μ. R uses the n-1 sample variance. Taking its square root gives a sample standard deviation, but unbiasedness is not preserved by nonlinear transformations. Variance and SD have different units.

R · illustrative example
x <- c(5, 7, 8, 12, 13)
c(mean = mean(x), variance = var(x), sd = sd(x))
sum((x - mean(x))^2) / (length(x) - 1)

中位数与分位数 / Median and quantiles

中位数描述中间位置，比均值更不容易被极端值拉动；分位数描述分布位置，例如 0.9 分位数附近约有 90% 的总体取值不大于它。样本分位数有不同插值定义；R 的 quantile() 默认 type=7。小样本时，不同定义可能给出不同数值。

The median is less sensitive to extreme values than the mean. Quantiles locate positions in a distribution; sample versions require conventions for interpolation. State the convention when exact numerical agreement matters.

R · illustrative example
quantile(x, probs = c(0.25, 0.5, 0.9), type = 7)
median(x)

偏差与精度 / Bias and precision

偏差是估计量长期平均与真参数之差；精度描述抽样波动。MSE = Var(估计量) + Bias²，前提是相关二阶矩存在。一次结果离真值近，不能证明方法无偏；一次结果离得远，也不能证明方法错误。

Bias concerns the long-run centre of an estimator; precision concerns its spread. Mean squared error combines variance and squared bias when the relevant moments exist. One favourable draw cannot establish that an estimator is reliable.

CHAPTER 09

09 · 抽样分布：n 与 B / Sampling distributions

一张均值直方图里的每个数来自一整份样本。

两层重复 / Two levels

每次抽 n 个观测，计算一个统计量；把这个实验重复 B 次，得到 B 个统计量。n 控制每次估计的信息量；B 控制你对抽样分布的模拟精细度。增加 B 不会把每个样本的统计误差变小。

Draw n observations and compute one statistic. Repeat the whole experiment B times. Increasing n generally changes the sampling distribution; increasing B makes the simulated approximation more stable without changing the target sampling distribution.

原创模拟例子 / A separate simulation example

先用一个明确的理论总体建立直觉。这里每次从 Uniform(2,8) 抽 n=12 个数，总体均值是 5；重复得到的均值围绕 5 波动。向量 means 的长度是 B，不是 n。

Use a known population to separate theory from data issues. For Uniform(2,8), the population mean is 5. Each entry of means represents one complete sample of size 12, not one raw observation.

R · illustrative example
set.seed(512)
n <- 12
B <- 3000
means <- replicate(B, mean(runif(n, min = 2, max = 8)))
length(means)
c(centre = mean(means), spread = sd(means))
hist(means, main = "Repeated sample means", xlab = "Mean of 12 observations")

经验总体与抽样机制 / Empirical populations

对 penguins 的非缺失体重向量重复抽样时，要说明它是你设定的有限经验总体，还是用有放回重抽样近似某种抽样过程。replace=TRUE 可重复抽中同一值；replace=FALSE 一次样本中不重复抽同一行，且 n 不能大于可用行数。

When sampling from observed penguin measurements, declare what population and sampling mechanism the exercise represents. Sampling with replacement allows repeated selections; sampling without replacement has finite-population dependence. Neither alone establishes inference to all wild penguins.

R · illustrative example
mass <- palmerpenguins::penguins |>
  dplyr::filter(!is.na(body_mass_g)) |>
  dplyr::pull(body_mass_g)
set.seed(513)
one_sample <- sample(mass, size = 15, replace = TRUE)
mean(one_sample)
CHAPTER 10

10 · purrr、pull 与标量 / Reliable repeated calculations

迭代函数的输入、返回类型、输出长度要说清楚。

map_dbl 的契约 / The map_dbl contract

map_dbl() 对输入的每个元素调用一次函数，要求每次返回长度为 1、可转成 double 的结果。这里迭代编号只是重复次数的标签，不应误当样本大小；如果需要不同样本量，要明确传入不同的 n。

map_dbl() expects one numeric result per input element. Distinguish an iteration label from the sample-size argument. Returning a whole tibble or a vector of multiple observations breaks the scalar-output contract.

R · illustrative example
set.seed(611)
n <- 18
B <- 1000
means <- purrr::map_dbl(seq_len(B), function(iteration) {
  draw <- rexp(n, rate = 0.5)
  mean(draw)
})
stopifnot(length(means) == B, is.numeric(means))

pull 取列，不是取单元格 / Pull returns a column

summarise() 返回表格，即便只有一行一列；pull() 返回该列向量。如果还有分组，可能返回多个数，不能直接放进要求单一标量的 map_dbl()。检查 length()，而不是看到界面只显示几行就猜。

A one-cell table is still a table. pull() extracts a column, which is scalar only when it has one element. Remaining groups can silently make that column longer than expected.

R · illustrative example
one_number <- palmerpenguins::penguins |>
  dplyr::summarise(value = mean(bill_depth_mm, na.rm = TRUE)) |>
  dplyr::pull(value)
stopifnot(length(one_number) == 1)

先跑一次，再跑一千次 / Test one repetition first

把循环体拆出来，确认一次抽样得到 n 个值、一次统计得到 1 个值，再扩大重复次数。先检查函数返回类型和缺失值，不要用更多模拟掩盖一个错误的统计过程。

Inspect a single draw and its single statistic before scaling up. Large simulations amplify logical mistakes; they do not correct them.

CHAPTER 11

11 · 中心极限定理与标准误 / CLT and standard error

原始数据不需要自己变成正态。

标准化表述 / The standardised statement

若 X1,…,Xn 独立同分布，均值 μ 有限且方差 0<σ²<∞，则随 n 增大，sqrt(n)(X̄-μ)/σ 的分布趋近标准正态。这里趋近正态的是标准化样本均值的分布，不是单个 Xi 的分布。

For iid observations with finite mean and finite nonzero variance, sqrt(n)(X̄-μ)/σ converges in distribution to a standard normal variable. The statement is about repeated-sample means after standardisation, not about raw observations becoming normal.

SD 与 SE / Distinguish spread from uncertainty

SD 描述个体观测的分散；SE 描述估计量的抽样波动。iid 情形下样本均值的 SE=σ/√n，未知 σ 时通常用 s/√n 估计。样本量扩大四倍，理论 SE 减半；观测的 SD 不会因此自动减半。

SD describes variation among observations. The standard error describes variation of an estimator across samples. For an iid sample mean, SE=σ/√n; s/√n is a common estimate. Quadrupling sample size halves this theoretical SE, not the underlying population SD.

没有通用的 n=30 保证 / No universal threshold

收敛快慢取决于偏斜、尾部和目标精度。强偏斜常需要更大的样本；依赖数据、不同分布的观测或无穷方差需要别的条件和定理。不能把任何“均值直方图看着像钟形”当作 iid 或有限方差已被验证。

There is no universal sample-size cutoff. Strong skewness and heavy tails can slow approximation. Dependence or infinite variance can invalidate this classical version. A bell-shaped plot does not prove that its assumptions hold.

大数定律不是 CLT / LLN is not the CLT

大数定律说明样本均值随样本量增大靠近 μ；CLT 进一步描述误差按 √n 缩放后的形状。一个谈收敛到哪里，一个谈偏差如何分布。模拟时可以同时观察中心、宽度与标准化形状，但要分别解释。

The law of large numbers concerns convergence towards μ. The CLT describes the scaled fluctuations around μ. Keep location, spread and standardised shape as separate observations.

CHAPTER 12

12 · 均匀与指数分布实验 / Uniform and exponential experiments

固定模型，改变样本量，并公平地比较图。

已知理论值 / Known theoretical targets

Uniform(a,b) 的均值是 (a+b)/2，方差是 (b-a)²/12。Exponential(rate=λ) 的均值是 1/λ，方差是 1/λ²。R 的 rexp() 参数是 rate，不是均值；λ=0.5 对应均值 2。

A uniform population has mean (a+b)/2 and variance (b-a)²/12. An exponential population parameterised by rate λ has mean 1/λ and variance 1/λ². R uses rate: a rate of .5 therefore gives a mean of 2.

比较 n=8 与 n=64 / Compare two sample sizes

指数原始数据右偏，而多次样本均值的分布随 n 增大通常更接近对称、集中。下例将两张均值直方图使用共同分箱、横轴和纵轴范围；不要让自动缩放掩盖宽度差异。

Exponential raw data are right-skewed. Repeated sample means typically become more concentrated and less skewed as n grows. Use common axes and bins to avoid mistaking plot rescaling for a substantive change.

R · illustrative example
set.seed(712)
B <- 3000
m8 <- replicate(B, mean(rexp(8, rate = 0.5)))
m64 <- replicate(B, mean(rexp(64, rate = 0.5)))
breaks <- seq(0, max(c(m8, m64)) + 0.1, length.out = 35)
h8 <- hist(m8, breaks = breaks, plot = FALSE)
h64 <- hist(m64, breaks = breaks, plot = FALSE)
ymax <- max(c(h8$density, h64$density))
old <- par(mfrow = c(1, 2))
plot(h8, freq = FALSE, ylim = c(0, ymax), main = "n = 8", xlab = "Sample mean")
plot(h64, freq = FALSE, ylim = c(0, ymax), main = "n = 64", xlab = "Sample mean")
par(old)

标准化后比较形状 / Compare standardised shape

指数总体 μ=2、σ=2，所以 z=(均值-2)/(2/√n)。标准化把不同 n 的均值和标准误放到共同尺度，可以和标准正态参考形状比较。标准化图不能替代原尺度图：前者展示形状，后者展示估计误差的实际大小。

Here μ=2 and σ=2. Standardisation puts the distributions on a common scale for shape comparison. Retain an original-scale comparison too: standardisation intentionally removes the difference in spread.

R · illustrative example
z64 <- (m64 - 2) / (2 / sqrt(64))
hist(z64, probability = TRUE, main = "Standardised means", xlab = "z")
curve(dnorm(x), add = TRUE, col = "blue", lwd = 2)
CHAPTER 13

13 · 有限总体修正 / Finite-population correction

不放回抽样不是 iid 抽样。

抽得越接近全部，不确定性越小 / Near-census sampling

从固定 N 个数中简单随机、不放回抽 n 个时，同一样本内各次抽取的观测值负相关。令 S²=Σ(xi-总体均值)²/(N-1)，则样本均值的设计方差为 (1-n/N)S²/n。若抽到全部 N 个，均值不再有抽样波动。

Under simple random sampling without replacement from a fixed population of N values, Var(sample mean)=(1-n/N)S²/n, where S² uses denominator N-1. The sampling variance is zero at a census. This differs from independent sampling with replacement.

明确方差的分母 / Declare the variance convention

如果把总体方差定义为 σ_N²=Σ(xi-均值)²/N，则等价的 SE 为 (σ_N/√n)√((N-n)/(N-1))。两个公式不矛盾，只是方差分母不同。对有限经验总体使用 sd(population) 时，R 用 N-1 分母，配套修正应为 √(1-n/N)。

The equivalent formula using a denominator-N population variance is SE=(σ_N/√n)√((N-n)/(N-1)). Match the correction to the variance convention. R’s sd() uses N-1, so pair it with sqrt(1-n/N) in the fixed-population expression.

R · illustrative example
population <- seq(10, 100, by = 2)
N <- length(population)
n <- 20
se_without_replacement <- sd(population) / sqrt(n) * sqrt(1 - n / N)
set.seed(810)
means <- replicate(3000, mean(sample(population, n, replace = FALSE)))
c(theory = se_without_replacement, simulated = sd(means))

15 · 自查、讨论与支持 / Self-check and learning support

帮助别人理解下一步，而不是替他们完成整份练习。

三个诊断问题 / Three diagnostic questions

先问：你想算什么？你预计输出是什么形状？实际输出哪里不同？技术卡点常是对象、类型或运行顺序；概念卡点常是条件方向、分母、抽样单位或统计量含义。让学习者指着一个具体数解释，比直接给整段代码更有效。

Ask: What are you trying to calculate? What shape should the output have? How does the observed result differ? Separate object/type/order problems from misunderstandings about conditioning, denominators or sampling units.

常见错误快查 / Common mistakes

object not found：检查名字与前序代码块；could not find function：检查包加载与命名空间；mean 返回 NA：检查缺失值；map_dbl 长度错误：检查是否返回一张表或多个数；图宽度看不出变化：统一坐标轴；理论与模拟不符：先核对全部参数及 replace 设置。

For a missing object, check spelling and earlier chunks. For a missing function, check package loading. For NA summaries, inspect missingness. For map_dbl length errors, inspect the return object. For conflicting theory and simulation, compare parameters and replacement settings before increasing simulation size.

概念性验收 / Conceptual checks

不用看代码，解释：一个 sample mean 对应几只观测？n 与 B 哪个改变真实 SE？阳性率与阳性预测值有什么区别？为什么分组后的 n() 未必等于非缺失样本数？为什么原数据仍偏斜而均值分布更对称？若能准确回答，才算超越“代码跑通”。

Without reading the code, explain what one sample mean represents, how n differs from B, why the positive rate differs from positive predictive value, and why row count differs from usable measurement count. Explain why skewed raw data can produce more symmetric means.

进一步学习边界 / What comes next

最大似然估计、区间估计和假设检验是自然后续，但不要把“均值的 SE”误当成任何统计量都适用的公式。中位数、分位数、依赖数据及复杂抽样需要相应理论或合适的重抽样方法。

Likelihood, confidence intervals and tests are natural next steps. The mean’s standard-error formula is not universal: medians, quantiles, dependent data and complex sampling designs require appropriate theory or resampling methods.

17 · 补充：最大似然估计 / Maximum likelihood

Optional conceptual bridge · 本周公告列为可选补充，不是上机的首要任务。

固定数据，比较参数 / Hold data fixed

概率模型通常给定参数后描述可能的数据；似然则把已经观察到的数据固定，比较哪些参数使这些数据更符合模型。似然函数不因此变成参数的概率分布，不能直接把“最大似然”称为“参数最可能的后验值”。

A likelihood treats observed data as fixed and varies the model parameter. It is not automatically a probability distribution over parameters; maximum likelihood is not the same as a maximum-posterior estimate.

Bernoulli 例子 / A Bernoulli example

n 个独立 Bernoulli 观测中有 k 次成功，L(p)=p^k(1-p)^(n-k)。在 0<k<n 时，对数似然导数为 k/p−(n−k)/(1−p)，令其为零得到 p̂=k/n。全失败或全成功的最大值在边界 p=0 或 p=1。

For n independent Bernoulli observations and k successes, the likelihood is p^k(1-p)^(n-k). The interior maximum is p-hat=k/n; all-failure and all-success samples attain boundary maxima.

为什么使用 log？ / Why logs?

对数把乘积变成和，数值上通常更稳定，而且单调性保证最大位置不变。估计结果仍依赖模型及抽样假设；数据很多不代表模型假设自动成立。下面是在独立原创例子中用网格观察峰值。

Logs turn products into sums and preserve maximizers. More data do not fix an invalid model. This independent grid example illustrates the peak rather than replacing a derivation.

R · illustrative example
n <- 20; k <- 7
grid <- seq(0.001, 0.999, length.out = 999)
log_likelihood <- dbinom(k, size = n, prob = grid, log = TRUE)
grid[which.max(log_likelihood)]
k / n
plot(grid, log_likelihood, type = "l", xlab = "p", ylab = "Log likelihood")
二项系数不依赖 p，因此用成功总数的二项似然给出同一个最大位置。 / The binomial coefficient is constant in p, so the maximizer is unchanged.
