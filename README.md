# SCEM Week 2 · Bilingual study companion

**Read the website:** https://zhouyi-xiaoxiao.github.io/scem-study-guide/

An independent, original Chinese/English learning guide for R data wrangling, Bayes' theorem, point estimation, sampling distributions and the central limit theorem.

## Included
- Searchable, mobile/tablet-friendly single page, bilingual display and large-text mode.
- Original concept explanations, teaching prompts, pitfalls, glossary and readiness checks.
- Browser-only interactive Bayes and CLT demos. These are JavaScript demonstrations, not R execution.
- `examples.R`: original R examples and checks. R/RStudio is not installed on the preparation machine, so these examples have not been executed there.
- `PRACTICE.md`: original guided practice, distinct from the official lab sheet.
- Downloadable self-contained `index.html` for offline reading; linked files and external sources require separate download/network.
- Local-only learning progress. No analytics, tracking, or network submission of progress.

## Official course material
Use the [authenticated Blackboard organisation](https://www.ole.bris.ac.uk/ultra/organizations/_271641_1/outline) for the current course materials and exact assignment specifications. This is not an official University publication and is not an official solution key.

The public repository does **not** include restricted lecture files, hidden answers, student data, internal staff messages, private calendars, or personal teaching allocations. It covers Week 2, not every week of the course.

## Running
Open `index.html` in a browser, or serve this folder with a static HTTP server. Run the R script in R/RStudio; the optional data-wrangling section uses dplyr and palmerpenguins. Package installation is a separate, explicit action.

Content checked against the Week 2 topic structure on 2026-10-01 (Europe/London). Formal course instructions take precedence.
